## What It Cleans

1. User Temp Files
2. Windows Temp Files
3. Windows Update Cache
4. DNS Cache
5. Thumbnail Cache
6. Windows Error Reports
7. Browser Cache (Chrome + Edge)
8. Windows.old Folder
9. Disk Cleanup (built-in)

## Options

- `A` = Run all steps automatically without asking
- `M` = Run in manual mode and confirm each step

## Usage

Run the batch file and choose one of the available modes when prompted:

```text
Enter your choice (A or M):
```

## Notes

- Run the tool as Administrator for best results.
- Some cleanup steps may require elevated permissions.
- The Windows.old cleanup step can remove the previous Windows installation folder.
